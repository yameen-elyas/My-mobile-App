# Module 2: Technical Analysis — Unit 1, Pathway 2: Setup Android Studio & First App

## Overview
Module 2 covers **Unit 1, Pathway 2**: installing Android Studio, understanding the tooling (Gradle, the Android Emulator, the project structure Android Studio generates), and building/running the first Android app, **Greeting Card**.

---

## Codelabs Covered
1. **Download and install Android Studio** — environment setup, SDK Manager, AVD Manager (used to create the `Pixel_9` virtual device this portfolio's screenshots were captured on).
2. **Create your first Android app** (`GreetingCard/MainActivity.kt`) — a minimal Compose app rendering a single greeting.
3. **Run your first app on the Android Emulator** — building and installing a debug APK, launching it on a virtual device, and reading Logcat output.
4. **How to connect your Android Emulator** — device bridge (`adb`) fundamentals used to install apps and pull screenshots.

## Key Concepts
- **`ComponentActivity` + `setContent {}`**: the entry point that hosts a Compose UI tree inside a standard Android `Activity`.
- **`@Composable` functions**: `Greeting()` is a composable function — the `@Composable` annotation tells the Kotlin compiler this function emits UI, not a return value.
- **`Modifier`**: chainable UI parameters (here, `Modifier.padding(24.dp)`) that adjust how a composable is measured, laid out, and drawn.
- **`MaterialTheme` / `Surface`**: the root theming wrapper and a themed background container, both standard scaffolding generated by Android Studio's "Empty Activity" Compose template.

## How This Was Verified
The app was compiled into a debug APK, installed on the `Pixel_9` emulator via `adb install`, launched, and captured with `adb shell screencap`. The real rendered screenshot is in `Screenshots/`.
