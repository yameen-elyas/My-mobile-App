## 🚀 How to Run

### Kotlin Source Code

For Kotlin console-based exercises:

1. Open the `.kt` source file.
2. Open it using IntelliJ IDEA or another Kotlin-compatible environment.
3. Make sure Kotlin is configured.
4. Run the `main()` function.
5. Review the console output.

Kotlin exercises can also be tested using the official Kotlin Playground:

https://play.kotlinlang.org/

---

### Android Projects

For Android Studio projects:

1. Open **Android Studio**.
2. Open the relevant Android project.
3. Allow Gradle to synchronize.
4. Connect an Android device or start an Android Emulator.
5. Build the project.
6. Run the application.
7. Verify the application's functionality.
8. Capture screenshots where required.

The applications are developed using **Kotlin and Jetpack Compose**.

## 💭 Reflection

This portfolio represents my practical progression from fundamental Kotlin programming to building interactive Android applications using Jetpack Compose.

The learning process helped me understand that Android development is not only about creating visual interfaces. A functional application requires programming logic, state management, user interaction, appropriate application structure, and continuous testing.

Kotlin fundamentals such as variables, functions, conditions, classes, and lambdas provide the programming foundation for Android development. Jetpack Compose then builds on this foundation by allowing user interfaces to be created using composable functions.

One of the most important concepts learned is **state-driven UI**. Understanding how state changes can trigger recomposition helped me understand how interactive applications respond to user actions.

The practical projects also provided experience with debugging and testing. Running applications in an emulator makes it possible to identify implementation problems that may not be obvious when looking only at source code.

Overall, this portfolio demonstrates my development from basic programming concepts toward practical Android application development and provides a foundation for more advanced mobile application development.
